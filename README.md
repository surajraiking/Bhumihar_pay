# Suraj Rai Pay

Original all-in-one digital payments and everyday-services interface by **Suraj Rai**.

## Included
- UPI-oriented Send/Receive/Scan/QR flows
- Payment-link and merchant-QR entry points
- Bank & UPI directory entry
- Recharge, bills, FASTag, travel, insurance and AutoPay service architecture
- Security-first messaging
- Mobile-first PWA and offline shell

## Live integration boundary
Real money movement, recharge, BBPS, FASTag, insurance, travel and mandate operations require authorized providers/PSPs/banks. This project never fakes successful transactions and never requests UPI PINs or OTPs.

NPCI's August 2026 statistics report 752 banks live on UPI; the live ecosystem changes over time, so the app should use official/current member data rather than hard-coding an outdated count.
